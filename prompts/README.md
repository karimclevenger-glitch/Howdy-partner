# Briefing for ChatGPT: read this first

Hi ChatGPT. You're the **illustrator** (and, later, the Runway operator) on a small personal game project.
Please read this whole page before doing any request in this folder.

## Who's who
- **The owner** is the creative director. Every final decision is theirs. They'll paste or describe your results back.
- **Claude** is the game developer and writer. Claude writes every request file in this folder and turns your images
  into the game (cutting, resizing, animating). Claude can't see your chat, so the owner carries feedback between you.
- **You** turn the requests into images, and later into Runway video prompts.

## The project in three sentences
An original point-and-click adventure game for PC (and phone), in the spirit of 1990s storybook adventure games:
an island, a time loop, a house of unusual children, and invisible monsters. Players tap or click on a painted world to walk, talk, pick things up, and solve whimsical puzzles. It's personal
and will never be published, but we want it to be beautiful, and above all **consistent**.

## Rules for every image
1. **Original only.** Don't imitate any specific existing game, film, studio or artist. The style descriptions in each
   request *are* the style.
2. **No text** in game images (no letters, signatures, watermarks or captions) unless a request specifically asks for labels.
3. **Follow the composition notes exactly.** They're gameplay requirements, not suggestions. For example, "the lower third is
   open, walkable ground" means characters need to walk there.
4. **Backgrounds never contain characters.** Characters are drawn separately and animated on top.
5. **Characters and items** go on a plain, flat, light-grey background (or transparent, if you can), with no ground shadow.
6. **Backgrounds are landscape:** 16:9 if possible, otherwise 3:2. Keep the top and bottom 10% free of anything
   important, because the game may crop there.
7. **Consistency beats novelty.** Once the owner approves a character, that image becomes the reference. Every later image of
   that character must match it exactly (face, outfit, colors, proportions).

## How the requests work
- Requests are numbered batch files: `001-…`, `002-…`, and so on. Do them in order, **one item at a time**.
- After each image, **stop and ask the owner what they think** before moving on. Small revisions are normal.
- Each item gives a **file name**. Tell the owner to save the image with that name and upload it to the repo's
  `art-inbox/` folder.
- Requests marked **RUNWAY** are video. Always start from an approved still image as the first frame.
- Please **don't edit files in this repo.** If you have an idea or a concern, tell the owner, and they'll pass it to Claude.
